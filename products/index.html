What you can run, and what you can ask for.

Two tools you can install right now without talking to anyone, and one desktop application that is in private testing on macOS.

Open source · Apache‑2.0

assurance

Your agent says it is done. This tells you what it did not check. One command in a folder where you have used Claude Code or Codex: it reads that session and reports what the run covered and what it quietly skipped. No account, no network request, nothing sent anywhere.

Open source · Apache‑2.0

rooms

A live session board for people working beside an agent. It shows what is happening as it happens rather than after it, so a teammate can see the work in progress instead of reading the summary afterwards. Runs offline and writes only inside your project.

Vinci, on macOS, in private testing

A signed, notarised desktop application on a live updater: the runtime that works out what a task needs, governs anything consequential it tries to do, and checks the result against conditions written before the run. It is not a download link yet, and early access is a conversation rather than a button.
