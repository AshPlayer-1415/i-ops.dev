I‑Ops, in a form a machine can quote.

This page exists because we build infrastructure for AI agents, so serving them a readable front door is the least we can do. Everything here is also true on the rest of the site. A plain markdown copy is at /agents.md, and an index for language models is at /llms.txt.

/01   what it is

One paragraph.

I‑Ops makes AI workers finish real tasks correctly: it works out what context a task needs, acquires what is missing under the company’s own permissions, governs consequential actions, and then independently verifies the outcome. The principle underneath it is that the worker that did the work does not get to declare it complete. The checks are computed by code, so swapping the model does not change the guarantee.

/02   what you can run

Three tools, Apache‑2.0, local.

assurance

What a run covered, spent, and may do.

Coverage over a folder, where an agent’s budget went, what it may touch, and what it is about to install. CLI, MCP server and a Claude Code plugin.

uvx assurance audit

rooms

Who built this, and which AI helped.

Attributes every commit to the person and the agent that co‑authored it, from git history alone.

npx iops-rooms week

rollcall

Every AI process here, and what a stop would miss.

Named from the resolved executable, never the command line, and it states what it did not look for.

npx iops-rollcall

Source for all three: github.com/i‑ops‑hq. Assurance is in Anthropic’s plugin directory and on the official MCP registry.

/03   what we do not claim

The honest half.

  • There are no paying customers and no design partners today.
  • Package download counts are mostly crawlers and mirrors. We do not report them as users.
  • The desktop app is an MVP in private testing. Some layers are designed and not built, and the documentation says which.
  • Nothing here governs an agent running on a machine we cannot see, and we do not claim a sandbox.
