Install and run the I-Ops assurance audit on this project, then report what it found.

1. It is a Python CLI published on PyPI as `assurance`. Run it with uv, which needs no
   install step of its own: `uvx assurance audit`
   If `uv` is missing, install it first (https://docs.astral.sh/uv/) or `pip install uv`.
2. Run it from the project root. It reads the most recent Claude Code or Codex session
   in that folder and reports what the session did NOT check.
3. It needs no account, no API key and no network. Do not add credentials. Do not send
   any file from this project anywhere.
4. Show me its findings verbatim. Do not summarise a finding away, and do not fix
   anything unless I ask you to.
5. If I want it to run after every one of your turns: `uvx assurance hook install`

Point 4 is the one that matters. An agent that summarises an audit has removed the thing you ran it for.
