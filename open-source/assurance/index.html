Tell us how your batch run lied to you.

A batch job reports success while records are missing, truncated, or quietly replaced by a retry under a new ID. The question worth answering is not did the job succeed but did every record you sent actually come back.

That check does not exist yet, and this page is how it gets built. What ships today is uvx assurance audit, which reads the coding‑agent session in a folder and tells you what it did not check. The batch check is being written from real failures people send us — it will run on your machine, like everything else here, and it will stay that way.

What this is for

If you run batch inference on Bedrock, OpenAI or Anthropic and you have ever found out late that a run was short, send us the shape of the failure. A research team did exactly that — eight failures from one production run. The first of them are already checks you can run; the rest are being built in the order they asked for.

Sign in, describe the failure, and we will tell you whether it is already covered or build the check.

What we store

Your email, your name, and which provider you use. That is the account.

assurance makes no network request of any kind — every check runs on your machine, against your files, with no key and no login, and that does not change by signing in. Signing in is for the conversation, not the tool. If we ever add something that sends data somewhere, it will be a command you choose to run and it will say what it sends.

Verify that rather than trusting it. There is no HTTP client anywhere in the install, dependencies included: 

pip download assurance -d a && cd a && for w in *.whl; do unzip -oq "$w" -d src; done
grep -rn "urlopen\|requests\.\|httpx\.\|aiohttp" src --include='*.py'

No output. The unzip step is the point — a wheel is a zip, so grepping the downloaded files directly finds nothing whether or not there is anything to find.

What we are building next

One run on one machine cannot tell you whether a fleet of runs came back complete. That is the next thing, and the people who sign in now are the ones we build it with.

Apache‑2.0. pip install assurance or uvx assurance. Source at github.com/i-ops-hq/assurance.
