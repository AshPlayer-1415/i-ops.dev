assurance

the verification layerPython · PyPI

Your agent says it is done. Assurance tells you what it did not check. It reads the Claude Code or Codex session in a folder and reports the coverage of the run, where the budget went, what the change reached, who owns what it touched, and what a dependency install is about to execute.

uvx assurance audit

Ships as a CLI, an MCP server on the official registry, and a plugin in Anthropic’s directory. Eight packages, so you can install only the part you want.

rooms

the observability layerNode · npm

Who built this, and which AI helped. Reads your git history and attributes every commit to the person and the agent that co‑authored it, so a reviewer can tell the two apart six months later. No account, no network.

rollcall

the containment layerNode · npm

What is actually running on this machine, and the ability to stop one of them. A per‑process view of the agents and tools a project has started, matched on the process name rather than a command line anyone can forge.

npx iops-rollcall

Source ↗ npm ↗

labs

two products, earlyPython · PyPI alpha

Crash Lab breaks things on purpose. It injects faults into an agent’s execution and then the host, not the agent, checks the returned state against predicates declared before the run and writes hashed evidence of what it found. An agent does not get to declare its own task complete, and now it does not get to do so while the ground is moving either.

Permission Simulator reads declared authorisation and answers whether a task may proceed, then exports the scenario as a file another tool can run.

uvx iops-crashlab --help

They share no runtime, only four JSON schemas. Both are 0.1.0a2 and labelled alpha because that is what they are.

why these are open

A check you cannot read is a check you have to trust.

We sell assurance. A closed tool that tells you it verified something asks for exactly the trust the product exists to replace, so the parts that do the checking are readable, forkable and removable in one step.

Every guarantee here is computed by code rather than produced by a model, which is why it survives a change of model. Of the twenty capabilities in the full product, eighteen never reach one.
