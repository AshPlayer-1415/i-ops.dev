One person reads everything that arrives here, so a short message with a real question gets a better answer than a form would.

Email

ashwinth@i-ops.dev reaches the founder directly. Useful for: whether I‑Ops fits a workflow you are trying to govern, what the open‑source tools do and do not check, access to the macOS application while it is in private testing, security disclosures, and press or partnership questions.

Issues and source

For a bug or a feature request in the open‑source tools, an issue on the repository is better than email — it is public, it is searchable by the next person with the same problem, and it gets a faster answer. github.com/i‑ops‑hq.

Security

If you have found something that affects users, please mail ashwinth@i-ops.dev rather than opening a public issue, and say so in the subject line. Each repository also carries a SECURITY.md with its own disclosure terms and what the tool does and does not defend against.
